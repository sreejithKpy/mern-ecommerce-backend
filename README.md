# MERN E-Commerce Backend

## Features

- JWT Authentication
- Admin & User Authorization
- Product CRUD
- Search
- Filter
- Sort
- Pagination
- Shopping Cart
- Address Management
- Order Management
- Admin Order Control

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Bcrypt
- Postman

## Installation

npm install

npm run dev
